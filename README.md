# OREN100 — сайт репетиторов

## Запуск
Нужен только Node.js 18+ (внешние пакеты не требуются).

```
node server.js
```
Сайт откроется на http://localhost:3000

При первом запуске создаётся администратор. Его пароль печатается в консоли **один раз**.
Чтобы задать свои данные, запустите так:

```
ADMIN_EMAIL=you@mail.ru ADMIN_PASSWORD=МойНадёжныйПароль node server.js
```
(Windows PowerShell: `$env:ADMIN_EMAIL="you@mail.ru"; $env:ADMIN_PASSWORD="..."; node server.js`)
Если указать ADMIN_PASSWORD при следующем запуске — пароль администратора будет сброшен на него.

Другие настройки: `PORT` (по умолчанию 3000), `DATA_DIR` (папка с базой, по умолчанию `data/`).

## Как это работает
- Записаться на занятие может только вошедший пользователь (проверяется на сервере).
- Админ-панель: `/admin.html` (ссылка «Админ-панель» появляется в меню после входа админом).
  Там все записи с контактами, классом, предметом, целью, комментарием, аккаунтом и сменой статуса
  (ожидает → подтверждена → проведено / отменена), а также список пользователей.
- История хранится в `data/db.json`: пользователи, сессии и все записи. Отменённые записи не удаляются —
  у них статус «Отменена», а время освобождается для других. Делайте резервную копию этого файла.
- Пароли хранятся только в виде хэша (scrypt), сессии — в HttpOnly-cookie.

## Расписание
- Репетиторы работают **каждый день с 14:00 до 21:00 по Москве (МСК)**: окошки 14:00, 15:00 … 20:00 (по 60 минут).
- Дни считаются на сервере от сегодняшней даты: показываются ближайшие 7 дней, прошедшее время закрыто.
  Записаться можно не позднее чем за 60 минут до начала. Страница сама обновляется раз в минуту.
- Настройки в начале раздела «Расписание» в `server.js`: `WORK_FROM`, `WORK_TO`, `BOOKING_DAYS`, `BOOKING_LEAD_MIN`.
  Если поменяете часы работы, поправьте также `WORK_FROM`/`WORK_TO` в блоке админ-панели в `public/script.js`.
- Правило отмены (не позднее чем за 24 часа) тоже считается по московскому времени.

## Календарь в админ-панели
Вкладка «Календарь» в `/admin.html`: неделя по дням и часам, фильтр по репетитору, переключение недель,
у каждого репетитора — часы за неделю, загрузка, сегодняшние занятия. Клик по занятию открывает контакты и смену статуса.

## Структура
- `server.js` — сервер и API
- `public/` — страницы сайта (HTML, CSS, script.js)
- `data/` — база данных (создаётся автоматически)

## На что обратить внимание при публикации в интернете
- Включите HTTPS (через nginx/Caddy или хостинг) — cookie тогда автоматически станут Secure.
- JSON-файл подходит для небольшого сайта; при росте нагрузки базу стоит заменить на SQLite/PostgreSQL.
- Расписание теперь автоматическое (см. ниже), вручную править даты в HTML не нужно.

## Что добавлено (версия от 29.10.2026)

### Согласие и политика конфиденциальности
- Страницы `privacy.html` (Политика конфиденциальности) и `consent.html` (Согласие на обработку персональных данных), ссылки — в подвале каждой страницы.
- При регистрации нужно поставить галочку согласия (проверяется и на сервере). Дата и версия согласия сохраняются у пользователя (`consentAt`, `consentVersion`).
- Аккаунты, созданные до этого обновления, при первой записи на занятие один раз подтверждают согласие в форме записи.
- **Обязательно:** в обоих документах выделены жёлтым поля `[...]` — впишите оператора (ФИО/ИП/организация), контактный email и проверьте текст у юриста. Если сменили текст документов — обновите `CONSENT_VERSION` в `server.js`.
- Базы данных граждан РФ по закону должны храниться на серверах в России — выбирайте хостинг в РФ. Шрифты Google Fonts подгружаются с серверов Google (это указано в политике); если скачаете шрифт Manrope к себе на сайт, удалите п. 5.4 политики.

### Восстановление пароля
- «Забыли пароль?» на странице входа → `forgot.html` → письмо со ссылкой → `reset.html`. Ссылка одноразовая и живёт 1 час, после смены пароля все прежние входы завершаются. Ответ сервера не раскрывает, есть ли такой email.
- Для отправки писем задайте переменные окружения (SMTP с шифрованием, обычно порт 465):
  `SMTP_HOST`, `SMTP_PORT` (по умолчанию 465), `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` (например `OREN100 <no-reply@ваш-домен.ru>`) и `SITE_URL` (например `https://ваш-домен.ru`).
- Если SMTP не настроен, ссылка печатается в консоль сервера, а администратор может выдать её вручную: **Админ-панель → Пользователи → «Ссылка для сброса»**.

### Кабинет репетитора (`/cabinet.html`)
- Роль «Репетитор» назначает администратор: **Админ-панель → Пользователи → колонка «Роль»** (выбрать Егора Артемовича или Валентину Александровну). Репетитор входит под своим обычным аккаунтом, в меню появляется «Кабинет». Репетитор видит только своих учеников и записи.
- Администратор открывает кабинет любого репетитора (переключатель сверху).
- **Занятия:** предстоящие, «нужно отметить итог» (прошедшие без отметки) и история; смена статуса, контакты ученика.
- **Закрытое время:** выходной на сегодня/завтра одной кнопкой, любая дата или период (отпуск), весь день или часы. Закрытое время недоступно для записи. Если в нём уже есть записи, кабинет предупредит и по подтверждению отменит их (ученик увидит «Отменена репетитором»).
- **Ученики:** карточка с контактами, **заметками** (добавить, изменить, удалить, привязать к занятию) и **историей занятий**. Заметки видят только репетитор и администратор.

### Перенос записи
- В «Моих записях» у активной записи есть кнопка **«Перенести»**: выбираете новое время, форму заново заполнять не нужно. Правило то же, что у отмены: не позднее чем за 24 часа до занятия; одну запись можно переносить до 3 раз (`MAX_RESCHEDULES` в `server.js`). Подтверждённая запись после переноса снова становится «Ожидает подтверждения», у репетитора она помечена «Перенесена с…».

### Обновление существующей базы
Файл `data/db.json` менять не нужно: новые разделы (`blocks`, `notes`, `resets`) создадутся автоматически, старые записи и пользователи сохраняются.
