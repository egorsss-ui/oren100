# OREN100 — сайт репетиторов

## Запуск
Нужен только Node.js 18+ (внешние пакеты не требуются).

```
node server.js
```
Сайт откроется на http://localhost:3000

При первом запуске создаётся администратор. Его пароль печатается в консоли **один раз**.
Чтобы задать свои данные, запустите так:

```
ADMIN_EMAIL=you@mail.ru ADMIN_PASSWORD=МойНадёжныйПароль node server.js
```
(Windows PowerShell: `$env:ADMIN_EMAIL="you@mail.ru"; $env:ADMIN_PASSWORD="..."; node server.js`)
Если указать ADMIN_PASSWORD при следующем запуске — пароль администратора будет сброшен на него.

Другие настройки: `PORT` (по умолчанию 3000), `DATA_DIR` (папка с базой, по умолчанию `data/`).

## Как это работает
- Записаться на занятие может только вошедший пользователь (проверяется на сервере).
- Админ-панель: `/admin.html` (ссылка «Админ-панель» появляется в меню после входа админом).
  Там все записи с контактами, классом, предметом, целью, комментарием, аккаунтом и сменой статуса
  (ожидает → подтверждена → проведено / отменена), а также список пользователей.
- История хранится в `data/db.json`: пользователи, сессии и все записи. Отменённые записи не удаляются —
  у них статус «Отменена», а время освобождается для других. Делайте резервную копию этого файла.
- Пароли хранятся только в виде хэша (scrypt), сессии — в HttpOnly-cookie.

## Расписание
- Репетиторы работают **каждый день с 14:00 до 21:00 по Москве (МСК)**: окошки 14:00, 15:00 … 20:00 (по 60 минут).
- Дни считаются на сервере от сегодняшней даты: показываются ближайшие 7 дней, прошедшее время закрыто.
  Записаться можно не позднее чем за 60 минут до начала. Страница сама обновляется раз в минуту.
- Настройки в начале раздела «Расписание» в `server.js`: `WORK_FROM`, `WORK_TO`, `BOOKING_DAYS`, `BOOKING_LEAD_MIN`.
  Если поменяете часы работы, поправьте также `WORK_FROM`/`WORK_TO` в блоке админ-панели в `public/script.js`.
- Правило отмены (не позднее чем за 24 часа) тоже считается по московскому времени.

## Календарь в админ-панели
Вкладка «Календарь» в `/admin.html`: неделя по дням и часам, фильтр по репетитору, переключение недель,
у каждого репетитора — часы за неделю, загрузка, сегодняшние занятия. Клик по занятию открывает контакты и смену статуса.

## Структура
- `server.js` — сервер и API
- `public/` — страницы сайта (HTML, CSS, script.js)
- `data/` — база данных (создаётся автоматически)

## На что обратить внимание при публикации в интернете
- Включите HTTPS (через nginx/Caddy или хостинг) — cookie тогда автоматически станут Secure.
- JSON-файл подходит для небольшого сайта; при росте нагрузки базу стоит заменить на SQLite/PostgreSQL.
- Расписание теперь автоматическое (см. ниже), вручную править даты в HTML не нужно.
